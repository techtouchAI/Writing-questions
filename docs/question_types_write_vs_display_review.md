# أنواع الأسئلة: ما يُكتب وما يُطبع (كتابة أسئلة فقط)

التطبيق **لكتابة الأسئلة وحدها**. لا يوجد في النموذج ولا في الواجهة ولا في PDF/Word
ولا في النسخة الاحتياطية أي مفهوم «إجابة»: لا صح/خطأ مختار، ولا خيار صحيح، ولا إجابة
نموذجية، ولا نسخة معلم. (كان هذا الملف تقريراً تاريخياً عن تصميم قديم فيه إجابات؛ استُبدل
بوصف الحالة الحالية.)

## الحالة المخزَّنة لكل نوع

| النوع (`QuestionType`) | ما يُخزَّن فقط | ما يُطبع |
|---|---|---|
| اختيار من متعدد (`multipleChoice`) | نص الفرع + النقاط + **نصوص الخيارات** (`QuestionOption`: `id`، `text`، `labelOverride`، `align`) | النص ← النقاط ← الخيارات بتسمياتها ( أ )، ( ب )... |
| صح أو خطأ (`trueFalse`) | نص كل عبارة (`BranchItem.text`) وترتيبها (`items`) ودرجتها (`marks`) وتسميتها (`labelOverride`) ومحاذاتها (`align`) | العبارات مرقّمة بالترتيب — لا شيء غيرها |
| تعاريف (`definitions`) | النص + النقاط | النص والنقاط |
| إكمال الفراغ (`fillInTheBlank`) | النص + النقاط | النص والنقاط |
| مقالي / شرح (`essay`) | النص + النقاط | النص والنقاط |

- `BranchItem`: `id`، `text`، `marks`، `labelOverride`، `align` — لا غير.
- `QuestionOption`: `id`، `text`، `labelOverride`، `align` — لا غير (لا علم «صحيح»).
- `BranchContent`: `type`، `text`، `options`، `items`، `plainText` (عرض النص والنقاط فقط).

## التوافق مع الملفات القديمة

الملفات والنسخ الاحتياطية القديمة قد تحمل حقولاً مثل `isCorrect` أو `modelAnswer` أو
`trueFalseAnswer` أو `teacherVersion` أو `trueFalseFormat`. تقرؤها `fromMap` بسلام
**وتتجاهلها** (لا تُنسخ إلى النموذج الجديد)، فلا تظهر في أي `toMap()` أو نسخة احتياطية
لاحقة. تحرس ذلك الاختبارات في `test/models/no_answer_state_test.dart` و
`test/models/no_answer_surface_test.dart`.

## المعادلات

يحتفظ النموذج الداخلي للمعادلات بصيغة LaTeX (`$...$`) كتمثيل تخزين فقط؛ أما ما يراه
المستخدم (المعاينة) وما يُطبع (PDF وWord) فهو معادلة مرسومة لا نص LaTeX خام.
