# أزرار مرحلة عرض الأسئلة (معاينة A4) — الأسماء والعمل وطريقة التأثير وطريقة العمل

> مرجع تفصيلي لكل زر يظهر للمدرس في **مرحلة عرض الأسئلة** (المعاينة A4 / WYSIWYG)،
> مع اسم الزر، ووظيفته، وما يحدث فعليًا عند الضغط، وكيفية عمله في الكود.

- **النطاق**: `WizardStep.preview` ← `ExamPreviewScreen` وملحقاتها
  (`PreviewToolbar`، `SmartExamToolbar`، أدوات العناصر العائمة، حواراتها، ومحرر المعادلات).
- **الحالة المرجعية**: الشيفرة عند `ad95e47` (فرع `arena/01a0edcf-writing-questions`)، 2026-09-29.
- **المرجع المرافق**: هذا الملف *دليل أزرار* (الاسم/العمل/التأثير/طريقة العمل)؛
  أما تقرير الأعطال والإصلاحات ونتائج التدقيق فمكانه
  [`preview_buttons_audit.md`](preview_buttons_audit.md).
- **الاتفاقيات**: «طريقة التأثير» = ما يراه المستخدم مباشرة بعد الضغط (أو سبب انعدام الأثر)،
  و«طريقة العمل» = سلسلة الاستدعاء الداخلية مع الموضع في الملف.
  الأرقام بين قوسين مثل `exam_preview_screen.dart:3119` هي أرقام أسطر في نسخة المستودع الحالية.

## 7) مسارات كاملة لأزرار مركّبة (خطوة بخطوة)

1. **حفظ الورقة** (زر #4 أو #33): `_save()` → `_libraryProvider()` → إن غاب المزوّد:
   «الحفظ غير متاح في هذا السياق» → `_isBusy = true` → `provider.saveDocument(document.touched())`
   → «تم حفظ الورقة.» أو «تعذر حفظ الورقة…» → `_isBusy = false`.
2. **تصدير PDF** (من الحوار #6.3): يستدعي `resolvePageAssignments` عدّ الصفحات المطبوعة →
   `buildDocumentPdfBytes` → يحفظ الورقة في المكتبة (حفظ صامت لا يمنع التصدير) →
   يفتح `PdfPreviewScreen` → عند أي خطأ: رسالة + `ExportFileService.logError`.
3. **إدراج صورة** (#28/#46): `pickImageBytes` → `bytes == null` = إلغاء (بلا أثر) →
   `_addImageToSelection` → `_addAttachmentToSelection` → `_withDefaultPosition` (صفحة السؤال النشط،
   `dx = 8`، `dy = أعلى الكتلة + 8`) → `controller.addFloatingElement` → يُحدَّد العنصر.
4. **معادلة حرة** (#41/#47): المحرر → `_stagedFormula` → تظهر البطاقة في الشريط →
   إمّا سحبها على الورقة (`_acceptFormulaDrop` → `_dropFormulaOnPage`) أو نقرة على موضع
   (`_placeStagedFormula`) → تُنشأ `FloatingElement(formula)` ويُحدد العنصر، ويُفرَّغ المرشح.
5. **قفل التحريك** (#7): يمنع ثلاثة مسارات فقط — سحب السؤال/الفرع (`onWillAcceptWithDetails`)،
   سحب العناصر (يُبنى المحتوى بلا ساحة إيماءات)، وإسقاط المعادلة؛ ويخفي المقابض وشريط العنصر.
   **لا يمنع** الكتابة ولا فتح الحوارات ولا التنسيق.

## 9) فهرس أسماء الأزرار (جرد كامل)

**شريط التطبيق**: العودة للأسئلة — إعدادات الورقة — حفظ الورقة.

**شريط الأدوات**: تراجع — إعادة — قفل التحريك/فتح القفل — تصغير — نسبة التكبير — تكبير —
ملاءمة الورقة للشاشة — توسيط الورقة — تحديد متعدد — نوع الخط — حجم الخط — عريض — مائل —
تحته خط — محاذاة لليمين — توسيط — محاذاة لليسار — ضبط — تباعد الأسطر — المسافة بين الفقرات —
المسافة بين الأسئلة — لون النص/لون عنوان السؤال — إطار حول التحديد — إدراج صورة — إدراج شكل
(مستطيل، مربع، دائرة، مثلث، خط، سهم) — مربع نص — إضافة فاصل — شريط الصيغ والوسائط — حفظ — PDF — Word.

**الشريط الذكي**: نص — رياضيات — كيمياء — فيزياء — وسائط | سؤال جديد — فرع جديد — سطر جديد —
ملاحظة للمعلم — آية قرآنية | محرر المعادلات — تحرير معادلة — كسر/جذر/أس/فرعي/متكامل/مجموع/نهاية/معادلة —
ماء/ثاني أكسيد الكربون/حمض الكبريتيك/الأمونيا/سهم تفاعل/تفاعل عكوس/معادلة أيونية —
قوانين نيوتن/نسبية/قانون أوم/الشغل/سرعة/متغير | صورة — معادلة حرة — مثلث — دائرة — مربع —
مستطيل — خط — سهم — مربع نص — فاصل | إلغاء الإدراج (للمعادلة المرشّحة).

**داخل الورقة**: الترويسة (تحديد) — مقبض سحب السؤال — تسمية السؤال — إضافة فرع — نسخ السؤال —
تثبيت تسمية السؤال — حذف السؤال — مقبض سحب الفرع — تسمية الفرع — درجة الفرع — نسخ الفرع —
تثبيت تسمية الفرع — إدراج/تحرير معادلة — حذف الفرع — إضافة نقطة — تسمية الخيار — × الخيار —
+ خيار — تسمية النقطة — حذف النقطة — الفاصل (النقر) — السماكة —
